This course aims to take you all the way from zero Python to knowing the nuts and bolts of how it works, and being able to read in, process, and visualise data. 

[Python](https://www.python.org/) is the world's most popular programming language, and has a vast array of uses from data analysis to website programming, image and video analysis, AI tasks, and much more. It will work on all of the major operating systems, and there are even versions of Python for small embedded devices like the microcontrollers that are in smart home devices.

In our everyday work, we use Python to speed up repetive tasks, and for much of our biological data analysis. Python has the benefit of being easy to run, reasonably quick to execute, and is a very nice language in which to write code.

### Course Structure

This course is organised into five separate "episodes", each of which builds in complexity. You should follow these episodes through in order, as subsequent episodes will use concepts learned in previous ones. The [fifth and final episode](05_Extra_Exercises.md) has some extra, advanced exercises that you can try if you get through the previous four episodes.

These materials have been built using [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs).
