## Google Colab Setup

You will be writing and running all of the code for this course using the free, cloud-based Python environment [Google Colab](https://colab.research.google.com) in your web browser, as this is the easiest cross-platform tool for everyone to use, and requires zero setup. Google Colab should work equally well in the Chrome, Safari, or Firefox web browsers.

To get started, go to [https://colab.research.google.com](https://colab.research.google.com) and sign in with a Google account. Click **"New notebook"** to create a new notebook, and you should see an interface like the one below.

![Google Colab interface](fig/01_colab_interface.png){alt="Screenshot of the Google Colab interface showing a new notebook"}

We would suggest giving your Google Colab notebook a sensible name (like "Intro to Python") and saving it, so you can refer back to it in the future if you need to refresh your memory.

## Required Data

Some of the episodes require data that is read in from files. You can download a [zip file of the data](data/intro-to-python-data.zip) that contains everything you'll need. The data are also [available on GitHub](https://github.com/sandyjmacdonald/intro-python-course).
